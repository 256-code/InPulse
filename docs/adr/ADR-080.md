# ADR-080：登录页直达单点登录

- 状态：Accepted
- 决策日期：2026-10-16
- 接受依据：用户 2026-10-16 明确要求「以后只用单点登录，本地的登录页面可以不用了，登录页面呈现的直接就是单点登录的登录页」。
- 修订：修订 [ADR-036](ADR-036.md) 决策 1、2、4、5 的前端入口部分（ADR-032 决策 7 的「默认自动跳转」曾被 ADR-036 改为「默认本地口令表单 + 图标入口」，本次恢复为默认直达单点登录，本地口令表单退居隐藏应急入口）。ADR-032 的 OIDC 流程、两条 302 路由、`securityFlow` allowlist、用户映射与 JIT 开通、本地会话与 fail closed 语义全部不变；ADR-036 建立的 `/login?local=1` 管理员应急入口与 fail closed 回落目标 `/login?local=1&sso=disabled` 继续保留。

## 背景

1. 平台账号已确定今后只经统一身份认证产生（本地口令账号仅保留管理员应急）；ADR-036 的「默认本地口令表单、手动点击图标才进入统一身份认证」与「只用单点登录」的实际使用方式不符，用户要求登录页直接就是统一身份认证。
2. 统一身份认证是否可用由服务端在 `/auth/sso/start` 处以 302 回落判定，前端没有可预先查询的公开信号（ADR-036 背景 2），因此「登录页直接就是 SSO」只能在进入 `/login` 后立即整页发起 `start`，由服务端决定放行到 Casdoor 或 fail closed 回落。
3. `/login?local=1` 是公司统一身份方案要求的超级管理员应急口令入口（ADR-032 背景），不能随本次调整移除；本地口令登录的校验、限流与会话语义保持现状。

## 决策

1. `/login`（含 `?from=`）在匿名态不再渲染本地口令表单，而是立即整页跳转 `/api/v1/auth/sso/start?returnTo=<目标>`（`window.location.replace`，浏览器导航而非 XHR），跳转期间展示品牌加载态；会话状态未知（前端 `status==="loading"`）时先展示加载态、不跳转；已登录访问 `/login` 仍按 `from` 回跳目标页；会话状态探测失败（`status==="error"`）时展示错误与手动「重新登录」，不自动跳转。
2. 仅 `?local=1`（管理员应急）与服务端 fail closed 回落的 `?sso=disabled` 两个分支渲染本地口令表单，且都不自动跳转（避免与 302 回落互相打转）：`sso=disabled` 显示「统一身份认证未启用，已切换到本地账号登录。」；本地表单页不再展示统一身份认证图标入口。
3. `?sso_error=<code>` 回落时不自动重跳、不渲染本地表单：顶部显示可读错误，下方提供「重新登录」按钮，由用户手动重试统一身份认证（避免统一身份认证持续故障时无限弹回）；管理员应急仍可自行访问 `/login?local=1`。
4. 退出登录与未登录态的「前往登录」语义不变，仍回 `/login`；用户随后被自动带入统一身份认证（IdP 会话有效时无感重登，属 OIDC 单点登录的预期行为；如需换号，由统一身份认证侧的登出行为决定）。
5. 服务端、契约与权限矩阵不变：`startSsoLogin` / `completeSsoLogin` 两条 302-only 路由、`securityFlow` 五条 allowlist、回落目标 `/login?local=1&sso=disabled` 与 `/login?sso_error=<code>` 的构造均保持现状；不新增公开的 SSO 可用性查询接口。

## 非目标（本期不做）

- 不删除本地口令登录路由、`PasswordService` 与 `/login?local=1` 应急入口（公司统一身份方案要求保留管理员应急预案；口令登录的最终退场另行 ADR）。
- 不改变 OIDC 协议实现、状态码语义、数据库迁移与依赖。
- 不引入服务端渲染标记或新的公开状态接口。

## 影响与验证

- 前端：`apps/web/src/pages/login/LoginPage.tsx`（自动跳转、加载态与回落分支）、`apps/web/src/pages/login/login-page.css`（加载态样式，移除不再使用的图标入口样式）、`apps/web/src/app/layout/AppLayout.tsx`（退出/未登录跳转注释同步）、`apps/web/src/features/auth/sso-navigation.ts`（注释同步）。
- 测试：`LoginPage.test.tsx` 覆盖「匿名默认自动整页跳转并携带 `from`」「缺少 `from` 回落站点根」「`loading` 不跳转」「`local=1` 渲染表单且不跳转」「`sso=disabled` 提示未启用且不跳转」「`sso_error` 显示错误、点击才重试」「已登录回跳」「会话状态异常显示错误与重试」；E2E `auth.spec.ts` 覆盖「匿名直达受保护页面 → 自动发起 SSO → 未配置时回落到隐藏口令入口」「默认 `/login` 自动发起 `start` 并携带 `returnTo`」「退出登录落干净登录页」；`csp.spec.ts` 与 `record-lifecycle.spec.ts` 改用 `/login?local=1` 以避开自动跳转。
- 文档同步：`AGENTS.md`、`README.md`、功能设计、系统设计、技术设计、测试矩阵；权限矩阵无需变更（服务端行为与授权语义未变）。

## 后续

- 若统一身份认证长期稳定且公司同意取消本地口令应急入口，另行 ADR 评估删除 `login` 路由、`PasswordService` 与 ADR-023 allowlist 的收缩。

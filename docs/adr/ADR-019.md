# ADR-019：Route Registry、权限矩阵与写接口幂等默认值

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

权限、CSRF、幂等、版本和并发策略散落在 Controller 时无法证明全部路由已覆盖；只保护“关键命令”也会遗漏普通编辑和成员变更。

## 决策

Route Registry 是所有 HTTP 路由操作策略的唯一登记点，并与可执行权限矩阵一一对应。所有非安全 HTTP 方法（POST、PUT、PATCH、DELETE）默认 `idempotencyRequired`；GET、HEAD 和纯校验路由登记为 `none`。写路由豁免必须在 Route Registry 显式登记原因，并通过新 ADR 评审。

## 影响与验证

写接口必须定义 Idempotency-Key 语义、窗口和重放响应；不能适用通用记录的路由要先形成可审查的例外。CI 检查每条路由字段齐全、权限矩阵有允许/拒绝用例，且不存在未备案的写路由豁免。

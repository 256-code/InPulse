# ADR-008：分 scope 串行审计哈希链与角色隔离

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

审计需要可追溯、可检测篡改，并在并发写入时避免分叉。

## 决策

按不可变 `chain_scope` 建链，锁定唯一链头后分配序号，使用 JCS 信封和版本化 HMAC-SHA256。业务写、审计写和链头更新处于同一事务；多个 scope 按 UTF-8 字节序加锁。runtime、audit_writer、audit_reader 与 archive writer 权限分离。

## 影响与验证

同一 scope 的审计追加会串行化。真实 PostgreSQL 测试必须覆盖至少 **100 个同 scope 并发业务事务**、初始化竞争、回滚、密钥轮换和恢复，断言无分叉、无序号缺口且每个业务事件恰有一条审计。

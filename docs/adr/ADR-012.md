# ADR-012：两类角色与创建者成员关系语义

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

业务只需要系统管理员和项目成员两类角色。将项目创建者解释成永久成员会形成未建模的第三种权限身份。

## 决策

项目创建时，创建者必须包含在初始成员中且不可在创建表单中取消。创建完成后，系统管理员可以按普通成员规则移除其成员记录；`projects.created_by` 只用于溯源、保持不可变，不授予额外权限，也不会因成员移除而清空。

## 影响与验证

被移除的创建者立即失去该项目访问权，历史创建人仍可追溯。测试必须覆盖创建时取消失败、创建后管理员移除成功、`created_by` 不变、权限立即失效与重新加入生成新成员历史。

# ADR-021：逐响应 nonce CSP

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

React 与 Ant Design 的运行时样式需要在不放宽内联脚本/样式策略的前提下工作。

## 决策

生产 HTML 每次响应生成至少 128 bit 随机 nonce，同时写入 CSP 和受控 bootstrap 元数据；AntD StyleProvider 使用同一 nonce。生产禁止 `script-src 'unsafe-inline'` 和 `style-src 'unsafe-inline'`。

## 影响与验证

`index.html` 必须 `no-store`，nonce 不记录也不复用。阶段 0 先运行 Report-Only E2E；不兼容即阻断并以新 ADR 更换方案或版本，不得静默放宽 CSP。

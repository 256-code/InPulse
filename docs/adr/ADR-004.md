# ADR-004：Zod Schema Registry 与 Route Registry 共同生成契约

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

单独的 DTO 或装饰器不能同时可靠表达数据结构、权限、安全与并发策略。

## 决策

`packages/api-contract` 中的 Zod Schema Registry 是请求与响应结构真相；Route Registry 是 HTTP method、path、状态码、安全和并发元数据真相。二者共同生成 OpenAPI 3.1 与 TypeScript Client。

## 影响与验证

禁止重复的 class-validator DTO 和手改生成客户端。CI 检查 Registry、Controller、OpenAPI 与客户端无漂移。

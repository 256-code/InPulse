# ADR-065：文档导入模板自带格式说明与解析器忽略说明行 / 围栏行

- 状态：Accepted
- 日期：2026-10-10
- 决策人：项目负责人（用户指示）与开发代理共同确认
- 关联：修订 [ADR-064](ADR-064.md) 第 2.1 节的模板语法行处理（「其余行 422」放宽为说明行与围栏行被忽略）；沿用 ADR-064 的模板版本 1、摘要 digest 与重复导入判定；不改路由数（仍 106 条）、权限、数据库与模板版本号。

## 1. 背景

用户指示（原话归纳）：

> 模板那边要说明清楚格式，以为可能以后有人会用其他 ai 来把项目填写进入这个模板，怕 ai 乱写导致匹配不上

当前事实（ADR-064 落地后）：

- 模板由前端 `DOCUMENT_IMPORT_TEMPLATE` 常量提供，「下载模板」只给出纯结构示例；字段名清单、层级、必填与两种模式差异等格式规则只存在于页面文案与 ADR 中，复制出去的模板文件不带这些说明。
- ADR-064 2.1 规定「只支持标题行与字段行；其余行 422 `LINE_UNRECOGNIZED`」：在模板里补充填写说明、或用代码围栏包裹整段文档，都会让整篇被判非法。
- 模板会被交给其它 AI 填写，字段名是解析匹配的唯一依据；AI 自创字段名或改写标题关键字时，模板本身没有任何可自证的填写约束，用户只能拿到 422 行级错误再回头改写。

## 2. 决策

### 2.1 模板本体自带说明行（以 > 开头）

- `DOCUMENT_IMPORT_TEMPLATE` 顶部以 `>` 引用行写入填写说明：三类行规则、逐字段名清单（项目 / 模块 / 功能 / 任务）、必填与格式（项目编码、负责人、优先级、截止）、两种导入范围差异，以及「字段名必须与说明完全一致、不要自创、不要改名」的显式约束；其后保留原示例结构。
- 说明行是文档的一部分，可保留也可删除；由于摘要 `digest` 仍按原文（含说明行）计算，增删说明行即视为不同文档——这与 ADR-064 的「同一文档禁止重复导入」语义一致，不做特殊处理。

### 2.2 解析器忽略说明行与代码围栏行

- 逐行 `trim()` 后以 `>` 开头的行、以三个反引号代码围栏或 `~~~` 开头的行被跳过：不计入文档内容、不产生问题、不参与任何字段解析；
- 只有说明行与围栏行的文档不视为有内容，仍按 `EMPTY_DOCUMENT` 处理；
- 其余无法识别行仍 422 `LINE_UNRECOGNIZED`（本次修订 ADR-064 2.1 的表述为：支持标题行与字段行，并忽略说明行与围栏行）；该错误文案同步更新，提示可用行类型与「后两者会被忽略」。

### 2.3 弹窗「格式速查」

- 粘贴区上方新增只读「格式速查」区块（`data-testid="document-import-format-guide"`）：标题层级、字段行形态、必填项、任务字段、围栏可粘贴；与模板说明保持同口径。
- 新增 `.import-format-guide` 样式（左竖线 + 淡底），不改弹窗结构与交互。

### 2.4 一致性测试（模板与解析器不漂移）

- API 解析器单测直接读取 `apps/web/src/features/document-import/DocumentImportModal.tsx` 的 `DOCUMENT_IMPORT_TEMPLATE`，拼接成文本后喂 `parseDocumentTemplate`：模板必须零问题，并断言项目 / 模块 / 功能 / 任务结构解析正确；
- 模板或解析器任一先行修改都会让该用例变红，防止「模板更新了、解析器没跟上」或反之。

### 2.5 非目标

1. 不升模板版本号（仍为模板版本 1）：语法集合未收紧，旧模板继续可用，忽略行属解析宽容化。
2. 不做 `.md` 文件上传与模板版本迁移工具（仍见 ADR-064 2.9）。
3. 不忽略其它前缀的行：`#` 注释行、`- [ ]` 待办行等仍 422，避免悄悄吞掉疑似业务内容。
4. 不改 digest 计算与重复导入判定：digest 仍按原文（含说明行）计算。

## 3. 影响

- **解析器**：`apps/api/src/modules/document-import/document-template.parser.ts` 增加忽略分支并更新 `LINE_UNRECOGNIZED` 文案。
- **前端**：`DocumentImportModal.tsx` 模板重写（说明行 + 原示例结构）与格式速查区块；`design-system.css` 新增 `.import-format-guide` 样式。
- **测试**：`document-import-parser.test.ts` 新增 3 例（忽略行、空文档、模板一致性）；`DocumentImportModal.test.tsx` 新增 1 例（格式速查与模板规则）。
- **契约与数据库**：无变更（Route Registry / Schema / OpenAPI / 生成客户端 / 迁移均不动，路由仍 106 条）。

# ADR-036：登录页默认展示本地口令表单，统一身份认证改为并列入口

- 状态：Accepted
- 决策日期：2026-09-18
- 接受依据：用户 2026-09-18 明确要求「登录时默认仍用既有的登录页面（本地口令表单），在登录框下方新增『或以统一身份认证登录』与单点登录图标，点击后再跳出到单点登录」。
- 修订：修订 [ADR-032](ADR-032.md) 决策 7 的前端入口部分（`/login` 默认自动跳 `/auth/sso/start`）。ADR-032 的 OIDC 流程、两条 302 路由、`securityFlow` allowlist、用户映射与 JIT 开通、本地会话与 fail closed 语义全部不变。

## 背景

1. ADR-032 把 `/login` 设计为「默认自动整页跳转统一身份认证」的透明入口，本地口令表单只在 `/login?local=1` 隐藏入口出现。实际使用中，退出登录、会话过期回到登录页时都会先渲染登录页再被自动跳走（2026-09-16 已修复退出路径的闪屏），用户仍希望保留既有登录页作为默认入口，并在同一页面上并列提供统一身份认证入口。
2. 立镖统一身份认证是否可用由服务端在 `/auth/sso/start` 处以 302 回落判定，前端没有可预先查询的公开信号；若要在渲染前隐藏或显示入口，就需要新增公开状态接口，超出本次需求。

## 决策

1. `/login`（含 `?from=`、`?local=1`）默认渲染既有本地口令表单，不再自动跳转 `/api/v1/auth/sso/start`。本地口令登录的校验、限流与安全语义不变。
2. 登录框下方新增「或以统一身份认证登录」分隔文案与单点登录图标按钮（图标使用单点登录系统页面同款立方体素材 `apps/web/public/casdoor-logo.png`），点击后同源整页跳转 `/api/v1/auth/sso/start?returnTo=...`；前端仍不得为此新增裸 `fetch`/`axios`，也不得新增查询 SSO 状态的接口。
3. SSO 可用性保持懒探测：点击入口后，未配置或配置非法时服务端仍按 ADR-032 302 回 `/login?local=1&sso=disabled&from=...`；登录页显示「统一身份认证未启用」并隐藏入口，本地口令表单继续可用。
4. `?sso_error=<code>` 回落时保留本地口令表单与 SSO 入口，错误提示置顶：用户可重试 SSO，或改用本地口令。
5. 退出登录与未登录态的「前往登录」一律回到 `/login`（不再直接整页跳 SSO）；`/login?local=1` 继续保留为管理员应急入口，语义等价于默认登录页。
6. 已登录访问 `/login` 仍按 `from` 回跳目标页，行为不变。

## 非目标（本期不做）

- 不改变 OIDC 协议实现、两条 SSO 路由的 302-only 契约、`securityFlow` 五条 allowlist、Route Registry 条数与生成客户端范围。
- 不新增公开的「SSO 是否启用」查询接口；不引入服务端渲染标记。
- 不改变本地口令登录的认证强度、限流与会话策略。

## 影响与验证

- 前端：`apps/web/src/pages/login/LoginPage.tsx`（默认本地表单 + SSO 图标入口）、`apps/web/src/pages/login/login-page.css`、`apps/web/src/app/layout/AppLayout.tsx`（退出/前往登录回 `/login`）、新增静态素材 `apps/web/public/casdoor-logo.png`。
- 测试：登录页单测覆盖「默认本地表单不跳转」「图标入口携带 from 跳转」「`local=1` 与默认一致」「`sso=disabled` 隐藏入口」「`sso_error` 保留表单与重试」「已登录回跳」；`AppLayout` 单测断言退出/未登录回登录页；E2E `auth.spec.ts` 覆盖「默认本地表单」与「点击入口回落隐藏口令入口」；服务端 302 回落断言不变。
- 文档同步：`AGENTS.md`、`README.md`、功能设计、系统设计、技术设计、测试矩阵；`docs/permissions.md` 无需变更（服务端行为未变）。

## 后续

- 若产品后续要求「SSO 未启用时直接隐藏入口」，需新增契约化的 SSO 可用性信号，另行 ADR。

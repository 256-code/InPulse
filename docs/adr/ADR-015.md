# ADR-015：同步 CSRF Token 与有限重签

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

Cookie Session 需要覆盖首次匿名登录、Session 轮换、刷新和多标签场景的 CSRF 闭环。

## 决策

采用同步 Token；提供匿名与已登录签发端点。所有非安全方法携带 `X-CSRF-Token`，数据库只存有限数量的短期 Token 哈希。客户端仅在明确的 Token 失效错误时重签一次，并以相同 Idempotency-Key/If-Match 重试。

## 影响与验证

同时使用 Origin/Referer 与 Fetch Metadata 纵深防御。测试覆盖首登、轮换、刷新、多标签、过期与无界重试阻断。

# ADR-003：NestJS 11.x 基线与 12.x 阶段 0 门禁

- 状态：Superseded
- 基线固化：2026-09-04
- 被替代：ADR-026

## 背景

NestJS 12.x 的 ESM、CLI 和插件生态迁移风险尚未在本项目中验证。

## 决策

候选基线暂用 NestJS 11.x 与 Express Adapter。阶段 0 必须完成 12.x 兼容性 PoC；升级或继续暂留都要新增 ADR，锁定实际补丁版本。

## 影响与验证

阶段 0 未完成该决策前不得把 12.x 写入生产清单。PoC 覆盖构建、CLI、Zod、Session、安全中间件和测试工具。

# ADR-018：PostgreSQL 数据卷与数据库角色分离

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

数据库初始化、迁移、运行、备份和审计访问具有不同权限与故障半径。

## 决策

PostgreSQL 18 数据卷挂载到镜像要求的 `/var/lib/postgresql`。数据库拆分 bootstrap、owner、migrator、runtime、backup、audit_writer、audit_reader 与 audit_archive_writer 角色，并使用独立 Secret。

## 影响与验证

runtime 不具备 DDL、原始审计读取或历史审计修改权限。迁移与集成测试验证每个角色的允许和拒绝操作。

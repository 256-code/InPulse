# ADR-011：Argon2id 与服务端 Session 认证

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

内部系统需要抗离线破解、主动会话失效和浏览器安全 Cookie。

## 决策

密码使用 Argon2id，参数下限为 `m=19 MiB,t=2,p=1` 并按生产机器向上调优。认证使用服务端 Session 和 `__Host-` HttpOnly Cookie；成功登录后轮换 Session 与 CSRF Token。

## 影响与验证

必须限制并发哈希计算并支持参数升级后的渐进重哈希。安全测试覆盖固定攻击面、Cookie 属性和 Session fixation。

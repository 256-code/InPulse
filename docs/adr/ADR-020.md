# ADR-020：加密逻辑备份与全新主机恢复验证

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

只有备份文件不足以证明系统可恢复；Session 恢复还可能错误地延续旧登录态。

## 决策

每 12 小时生成加密逻辑备份，排除 Session 数据；备份写入受限远端存储。定期在全新主机执行恢复并验证数据库链、迁移版本、审计锚点、应用健康，以及发布清单引用的版本化 Session、幂等 fingerprint、审计和 TOTP keyring 均可用。密钥不得与数据库备份同库存放。

## 影响与验证

恢复后旧 Session 全部失效，但未过期幂等记录仍须能使用其保存的 key version 比较请求摘要；对应 fingerprint key 至少保留到记录超过 30 天窗口并清理。Runbook 和演练报告必须证明 RPO/RTO、所有所需密钥版本的可用性、缺 key 时 fail closed 与回滚路径。

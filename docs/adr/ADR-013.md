# ADR-013：WorkflowModule 与显式 UnitOfWork

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

跨项目、任务、记录、审计和投影的写操作需要共享同一事务，又不能形成领域模块循环依赖。

## 决策

Controller 二选一调用单域 Use Case 或跨域 Workflow。WorkflowModule 通过 `UnitOfWork.run` 创建事务，并将同一 transaction handle 显式传给 CommandPort、Repository 与投影 Writer。

## 影响与验证

领域模块只暴露稳定 Port；事务内禁止使用全局 DB Client。真实 PostgreSQL 集成测试必须证明跨模块操作全部成功或全部回滚。

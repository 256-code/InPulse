# ADR-016：系统管理员 TOTP MFA 与重认证

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

成员管理、审计读取、用户启停等高风险动作不能只依赖普通登录态。

## 决策

所有系统管理员强制注册 TOTP MFA；高风险动作要求密码与当前 TOTP 重认证。重认证成功时以同一服务端事务时间原子刷新当前 Session 的 `reauthenticated_at` 与 `mfa_verified_at`，高风险门禁要求两者均在 5 分钟内。另一名 MFA 管理员可执行重置；单管理员场景只允许双人审批的离线恢复，重置后撤销全部 Session。

## 影响与验证

TOTP Secret 加密；恢复码只保存带独立 salt 和参数的 Argon2id 编码哈希，不使用普通 SHA-256，并防重放。测试覆盖管理员密码阶段绝不成为完整认证态、用户级注册 generation 的跨 Session/start-vs-confirm 竞争、双时间戳原子刷新与过期门禁、重置、恢复、会话撤销和审计记录。

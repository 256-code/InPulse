# ADR-017：固定版本、补丁与镜像 digest

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

只固定主版本或使用浮动镜像标签无法保证构建可复现，也难以审查安全补丁。

## 决策

运行时的 `engines` 或工具链约束声明受支持的主版本；生产依赖在 manifest 与 lockfile 中锁定经批准的精确补丁版本。生产镜像同时固定精确补丁 Tag 与真实 digest。Nginx 使用批准的 1.30.x 补丁系列，落库时固定具体补丁和 digest；切换 stable 系列必须新增 ADR。

## 影响与验证

阶段 0 锁定实际版本和 digest。依赖或基础镜像升级需要构建、迁移、安全与回滚验证。

## 阶段 0 定案记录（2026-09-09）

本项目生产镜像基础镜像已由受信镜像仓库解析并固定如下 digest：

| 用途 | 基础镜像 | 固定 digest |
|---|---|---|
| API / Migration 构建与运行时 | `node:24.20.0-bookworm-slim` | `sha256:ba849c60be29959425b8734d57b8b4b7d56f98edd9504c9af091d5281095a71e` |
| Web 运行时 | `nginxinc/nginx-unprivileged:1.30.4` | `sha256:cb92301e719d6639028de775fe8b28e15f58343aca5e5372001311958aafb300` |
| DB bootstrap | `postgres:18.6` | `sha256:4ef4dbc939d61acea57712655ddb4b4ab27419c913f94cca0cd57cb3ea3c2280` |

对应生产 Dockerfile 位于 `deploy/docker/`，CI 已在 `CI / workspace` 中按技术设计 §12.4 顺序
构建 API、Migration、Web、DB-bootstrap 四个镜像并执行 Trivy 镜像扫描；镜像 Tag/digest
绑定仍保留为发布环节的签名发布清单（本 ADR 只固化基础镜像 digest，不伪造自建镜像 digest）。

## 安全补丁记录（2026-09-09）

`node:24.20.0-bookworm-slim` 自带的 npm 11.19.0 全局工具链曾使 API 镜像 Trivy 扫描
报告 3 个 HIGH（brace-expansion、ip-address、tar）；它们来自基础镜像自带工具链，
不是仓库应用生产依赖。Node 官方当时尚未发布包含对应 npm 补丁的 Docker 镜像 tag，
因此本轮不移除扫描门禁，也不降级为忽略。由于 API/Migration runtime 只执行编译后的
Node 入口，`deploy/docker/api.Dockerfile` 与 `deploy/docker/migration.Dockerfile`
在 runtime 删除 `/usr/local/lib/node_modules`、`npm`、`npx` 与 `corepack`，并由
`scripts/check_deploy_refs.mjs` 校验防止回退。后续 Node 补丁镜像发布时，仍按上述
“影响与验证”独立走构建、迁移、安全与回滚评审。

# ADR-017：固定版本、补丁与镜像 digest

- 状态：Accepted
- 基线固化：2026-09-04

## 背景

只固定主版本或使用浮动镜像标签无法保证构建可复现，也难以审查安全补丁。

## 决策

运行时的 `engines` 或工具链约束声明受支持的主版本；生产依赖在 manifest 与 lockfile 中锁定经批准的精确补丁版本。生产镜像同时固定精确补丁 Tag 与真实 digest。Nginx 使用批准的 1.30.x 补丁系列，落库时固定具体补丁和 digest；切换 stable 系列必须新增 ADR。

## 影响与验证

阶段 0 锁定实际版本和 digest。依赖或基础镜像升级需要构建、迁移、安全与回滚验证。
